Unit 1 - Using Objects and Methods (15-25%)

Learning Objectives

  • Understand the reasons for programming and why Java is chosen as the teaching language.
  • Learn about variables and data types (primitive and reference).
  • Understand the role of expressions, assignment statements, and compound operators.
  • Master type casting and understand variable ranges.
  • Understand the concept of objects as instances of classes.
  • Learn how to create and store objects (instantiation).
  • Master the process of calling void and non-void methods.
  • Explore String objects, including concatenation, literals, and String methods.
  • Utilize the Math class and wrapper classes for various operations.

Key Concepts

  • Primitive Data Types: Basic data types in Java, such as int, double, boolean, etc.
  • Reference Data Types: Data types that refer to objects, such as String or custom classes.
  • Class: A blueprint or template that defines the properties (fields) and behaviors (methods) of objects.
  • Object: An instance of a class, which is a specific entity that has its own state and behavior.
  • Instantiation: The process of creating an object from a class using a constructor.
  • Method: A block of code that performs a specific task; can be void (no return) or non-void (returns a value).
  • String Class: A class for creating and manipulating strings; includes methods like length(), substring(), indexOf(), etc.
  • Math Class: A class providing mathematical operations like sqrt(), pow(), random(), etc.

Key Vocabulary

  • Data Type: A classification that defines the type of data a variable can hold.

Unit 2 - Selection and Iteration (25-35%)

Learning Objectives

  • Write and evaluate Boolean expressions using relational and logical operators.
  • Apply De Morgan's Laws to simplify or rewrite Boolean expressions.
  • Implement conditional control structures using if, if-else, and nested if statements.
  • Understand short-circuit evaluation in logical expressions.
  • Understand and apply while loops and for loops in Java.
  • Use loops to traverse and process data.
  • Write nested loops to solve complex problems.
  • Trace and debug iterative code.
  • Develop algorithms using String traversal and manipulation.

Curriculum Standards

  • The unit will take approximately 15 to 20 class periods to complete.
  • This unit contributes to a 25% to 35% weight in the AP exam.

  • How can we use loops to process each character in a string?
  • How do nested loops work, and how do they affect program efficiency?

Key Concepts

  • Boolean Expressions: Expressions that evaluate to true or false, using relational operators (==, !=, <, >, <=, >=) and logical operators (&&, ||, !).
  • Conditional Statements: Control structures that execute different code blocks based on conditions (if, if-else, nested if).
  • De Morgan's Laws: Rules for rewriting logical expressions: !(A && B) = !A || !B, !(A || B) = !A && !B.
  • Short-Circuit Evaluation: Java evaluates && and || from left to right and stops as soon as the result is determined.
  • Iteration / Looping: Allow code to repeat without rewriting the same instructions multiple times (while loops, for loops).
  • Nested Loops: Loops inside other loops, useful for working with grids, patterns, or multi-dimensional data.
  • String Traversal: Using loops to examine or manipulate each character in a string.

Relational and Logical Operators

Relational Operators

  • ==: equal to
  • !=: not equal to
  • <: less than
  • >: greater than
  • <=: less than or equal to
  • >=: greater than or equal to

Logical Operators

  • &&: logical AND
  • ||: logical OR
  • !: logical NOT

Unit 3 - Class Creation (10-18%)

Learning Objectives

  • Design and create classes with appropriate instance variables and methods.
  • Understand and implement constructors to initialize objects.
  • Use access modifiers (public, private) to control access to class members.
  • Distinguish between static and instance methods and variables.
  • Use the this keyword to reference the current object.
  • Implement method overloading to provide multiple methods with the same name but different parameters.
  • Apply encapsulation principles to create well-designed classes.

Curriculum Standards

  • The unit will take approximately 10 to 12 class periods to complete.
  • This unit contributes to a 10% to 18% weight in the AP exam.

Guiding Questions

  • What is a class, and how does it differ from an object?
  • Why is it important to design classes with appropriate instance variables and methods?
  • What is the purpose of a constructor, and when is it called?
  • How do access modifiers control access to class members?
  • When should you use static versus instance methods and variables?
  • How does the this keyword help in class implementation?
  • What is method overloading, and when is it useful?
  • How does encapsulation improve class design?

Key Concepts

  • Class Design: Creating well-structured classes that encapsulate related data and behavior.
  • Instance Variables: Variables that belong to an instance of a class and hold the object's state.
  • Instance Methods: Methods that operate on an instance of a class and can access instance variables.
  • Constructors: Special methods used to initialize objects when they are created.
  • Access Modifiers: Keywords that control the visibility and accessibility of class members.
  • Static Members: Members that belong to the class itself rather than to any specific instance.
  • this Keyword: A reference to the current object instance, used to distinguish between instance variables and parameters.
  • Method Overloading: Having multiple methods with the same name but different parameter lists.
  • Encapsulation: The practice of hiding internal details and providing controlled access through public methods.

Access Modifiers

  • public: Members are accessible from any class.
  • private: Members are accessible only within the same class.
  • Default (no modifier): Members are accessible within the same package (package-private).

Constructor Types

  • Default Constructor: No-argument constructor automatically provided if no constructors are defined.
  • Parameterized Constructor: Constructor that takes parameters to initialize object state.
  • Constructor Overloading: Multiple constructors with different parameter lists.

Unit 4 - Data Collections (30-40%)

Learning Objectives

  • Understand the concept of arrays as data structures for storing multiple values of the same type.
  • Create and initialize one-dimensional and two-dimensional arrays in Java.

  • Apply common array and ArrayList algorithms for searching, sorting, and data manipulation.
  • Work with text files for data input and output.
  • Understand the concept of recursion and write simple recursive methods.

Key Concepts

  • Array: A data structure that stores a fixed-size sequential collection of elements of the same type.
  • ArrayList: A resizable array implementation that can grow and shrink dynamically.
  • 2D Array: A data structure that stores elements in a grid or table format with rows and columns.
  • Array Traversal: Processing all elements in an array using loops.
  • Nested Loops: Using nested for loops to traverse 2D arrays or perform complex iterations.
  • Autoboxing/Unboxing: Automatic conversion between primitive types and their wrapper classes in ArrayLists.
  • Recursion: A programming technique where a method calls itself to solve a problem by breaking it down into smaller subproblems.
  • Base Case: A condition that stops the recursion, preventing infinite loops.
  • Text Files: Using file I/O to read data from and write data to text files.

Array and ArrayList Operations

Array Declaration and Creation

  • int[] numbers = new int[10]; - Create array of 10 integers
  • int[][] matrix = new int[3][4]; - Create 3x4 2D array

ArrayList Common Methods

  • add(element) - Add element to end of list
  • get(index) - Get element at index
  • size() - Get number of elements

Recursive Method Structure

Essential Components

  • Base Case: Condition that stops the recursion
  • Recursive Case: Call to the same method with modified parameters
  • Progress Toward Base Case: Each recursive call should move closer to the base case

Example: Factorial

public int factorial(int n) {
    if (n <= 1) return 1;  // Base case
    return n * factorial(n - 1);  // Recursive case
}
